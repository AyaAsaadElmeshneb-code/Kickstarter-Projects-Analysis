# 🚀 Kickstarter Projects Overview & Performance Analysis

## 📌 Project Overview
This project presents an end-to-end Power BI analytics report on **Kickstarter campaigns**, analyzing over 375K+ projects to uncover funding trends, success factors, category distributions, and backer engagement patterns.

## 📊 Dashboard Structure & Pages

* **🏠 Welcome / Landing Page:** High-level project navigation introducing core analytical pillars (Projects Analysed, Funding Success, Backer Engagement, and Key Metrics).
* **📈 Overview Dashboard:** Overall metrics highlighting total tracked projects (375K), successful vs. failed outcomes, total goals ($17B), total pledged ($3B), and distribution across top countries and categories.
* **✅ Successful Projects Analysis:** Deep dive into high-performing campaigns, goal vs. pledged comparisons by subcategory, and average pledged amounts by category and country.
* **❌ Failed Projects Analysis:** Breakdown of unsuccessful campaigns, funding gaps, and goal vs. pledged disparities using Decomposition Trees.
* **👥 Backers Analysis:** Detailed breakdown of 40M total backers, top categories/subcategories by backer support, and geographic distribution.

## 💡 Key Metrics & Insights
* **Total Projects Analyzed:** 375K
* **Successful Projects:** 134K
* **Failed Projects:** 198K
* **Total Backers:** 40M
* **Total Pledged:** $3B
* **Total Goals:** $17B

## 🛠️ Tools & Features Used
* **Power BI:** Data Modeling, Interactive Dashboards, Custom Navigation Buttons & Slicers.
* **Advanced Visuals:** Decomposition Trees, Treemaps, Map Visualizations, Filter Panels.
